# Tool CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a real `clj -T:rh` command that runs repetition-hunter on `.clj`, `.cljs`, and `.cljc` source files without requiring a REPL or `-e` forms.

**Architecture:** Add a small tool adapter namespace that validates `-T` arguments, normalizes `:path` and `:paths`, then delegates to `repetition.hunter.core/results-from-paths` and `print-results`. Keep analysis logic in the existing parser/source/core layers and keep CLI-specific UX isolated in the new tool namespace.

**Tech Stack:** Clojure, Clojure CLI tools mode (`-T` / `:exec-fn`), `clojure.test`, existing `repetition.hunter.core`

- [ ] **Step 1: Create `src/repetition/hunter/tool.clj` with helpers for validation and normalization**

Write this file:

```clojure
(ns repetition.hunter.tool
  (:require [repetition.hunter.core :as core]))

(def valid-sorts #{:complexity :repetition})

(defn- validate-sort [sort]
  (when (and sort (not (valid-sorts sort)))
    (throw (ex-info
             (str "Invalid :sort " sort ". Expected one of: :complexity, :repetition")
             {:sort sort})))
  sort)

(defn- normalize-paths [{:keys [path paths]}]
  (cond
    (and path paths)
    (throw (ex-info "Provide exactly one of :path or :paths" {:path path :paths paths}))

    (nil? path)
    (if (and (vector? paths) (seq paths) (every? string? paths))
      paths
      (throw (ex-info ":paths must be a non-empty vector of strings" {:paths paths})))

    (string? path)
    [path]

    :else
    (throw (ex-info ":path must be a string" {:path path}))))
```

- [ ] **Step 2: Add the tools entrypoint function that delegates to the engine**

Append this to `src/repetition/hunter/tool.clj`:

```clojure
(defn hunt
  [{:keys [path paths platform sort filter] :as opts}]
  (let [normalized-paths (normalize-paths {:path path :paths paths})
        validated-sort (validate-sort sort)
        results (core/results-from-paths normalized-paths
                                         {:platform platform
                                          :sort validated-sort
                                          :filter filter})]
    (core/print-results results)))
```
